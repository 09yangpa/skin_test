# CastShop · 肌肤护理手册（微信原生小程序）

交付给中国开发团队。直接用微信开发者工具导入**含 project.config.json 的本目录**，不是导入 miniprogram 子目录。无需 Flutter、npm install 或「构建 npm」。后端仍由 CastShop 提供，未包含服务器源码或密钥。

## 五分钟上手

1. 解压整个压缩包。开发者工具 → 小程序 → 导入 → 选择本目录；使用团队自己的小程序 AppID。仓库里的 touristappid 仅为占位符，不用于发布。
2. 编译。首页首选「开始访客测评」：无需注册、会员账号、手机号或微信授权登录。完成 12 题，按需拍摄或选择照片，勾选同意后生成真实的服务器报告。原始照片不离开设备，不保存测评历史。
3. 在公众平台将 https://kai.blacksmithio.com 加入 request 合法域名（miniprogram/config.js 的 guestBase）。独立的「先看看一份示例报告」只用于离线预览，绝不是访客测评的替代。
4. 只有测试可选会员服务时才需要 CastShop 会员、会员 API 域名和商品图片域名。apiBase 的默认值是会员生产地址，请换成获准的测试环境；会员模式会写入会员历史。访客故障时不切换到会员服务。

## 包含什么

- pages/home：真实访客测评为首选；可选邮箱密码登录、退出、最近一次报告、独立标记的静态示例。
- pages/survey：12 道简体中文题。按年龄分支，返回修改年龄会清除另一分支的答案。拍摄/相册任选一张；也可以只提交问卷。
- pages/report：访客结果包含综合分、肤质、五项指标、早晚步骤及注意事项，不提供历史或商品；会员版本包含综合分、肤质、五项指标、早晚护理、四周计划、推荐及需留意的成分、在售商品。只使用服务端结果，不伪造分数、不在客户端运行分析。
- pages/product：打开时再次核验商品状态，显示目录资料、匹配理由及已登记的相关成分。不捏造品牌译名或人民币价格。
- core/questions.js：界面为简体中文，value 保留原 App 的韩文协议值。
- core/report-copy.js、core/report.js：当前规则版本的中文展示词典；商品名、品牌名及未翻译的已登记成分保留目录原文。不将未识别的韩文诊断叙述冒充翻译。API 文案或版本变更后需同步词典。
- examples：虚构问卷的请求及响应样例，无令牌、无客户资料；tests：离线契约检查，可单独运行 npm test（Node 20+）。

原型依据：castshop-app-latest main 38f689529db00eeeca8a6708280aa648ea8ace52；配套 API aae75a233363820a483ff6fb232bf7960744c98e。当前引擎 todaycolor-simple-v1：12 种类型、5 项指标、最多 1 张正面照片；不是旧网页的 OpenAI、3 张照片或 OBNF 版本。
